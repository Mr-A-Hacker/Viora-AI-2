# Viora AI 2 (Raspberry Pi 4 / 5 Edition)

## ⚠️ Important: Target Hardware

This project was **made for Raspberry Pi 4 and Raspberry Pi 5**.

- Primary target: **Raspberry Pi 5**
- Supported minimum: **Raspberry Pi 4**
- OS expectation: **Linux (Raspberry Pi OS / Debian-based preferred)**

If you run it on other hardware, it may still work, but the intended setup, performance profile, and tooling are built around **Pi 4/5**.
